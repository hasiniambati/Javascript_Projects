# JavaScript Projects Collection

A collection of JavaScript projects built while learning modern web development. These projects demonstrate core JavaScript concepts, DOM manipulation, event handling, user interaction, and responsive UI design.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)

## Projects Included

### 1. Counter App
A simple counter application with increment, decrement, and reset functionality.

**Concepts Used:**
- DOM Manipulation
- Event Handling
- Variables and Functions

---

### 2. Dice Roller
A virtual dice rolling application that generates random dice values and displays corresponding images.

**Concepts Used:**
- Random Number Generation
- Arrays
- Dynamic Image Rendering

---

### 3. Digital Clock
A real-time digital clock displaying the current time.

**Concepts Used:**
- Date Object
- setInterval()
- Time Formatting

---

### 4. Number Guessing Game
An interactive game where users try to guess a randomly generated number.

**Concepts Used:**
- Conditional Statements
- Loops
- User Input Validation

---

### 5. Random Password Generator
Generates secure passwords based on selected criteria.

**Concepts Used:**
- String Manipulation
- Randomization
- Functions

---

### 6. Stopwatch Program
A stopwatch application with start, stop, and reset features.

**Concepts Used:**
- Timing Functions
- State Management
- Event Listeners

---

### 7. Temperature Conversion
Converts temperatures between Celsius and Fahrenheit.

**Concepts Used:**
- Mathematical Operations
- Form Handling
- Input Validation

---

### 8. Checked Property Demo
Demonstrates the use of checkbox and radio button properties in JavaScript.

**Concepts Used:**
- Form Controls
- DOM Properties
- Conditional Logic

---

### 9. Random Generator
A utility project that generates random values based on user interaction.

**Concepts Used:**
- Random Number Generation
- Event Handling
- DOM Manipulation

---

### 10. Rock Paper Scissors Game
A fun and interactive game where users play Rock, Paper, Scissors against the computer. The game randomly generates the computer's choice, determines the winner, updates scores, and provides an engaging user experience.

**Concepts Used**
- DOM Manipulation
- Event Handling
- Conditional Logic
- Functions
- Arrays
- Random Number Generation
- Score Tracking

---
